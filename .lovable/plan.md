
# План исправления отображения баннеров на мобильных устройствах и планшетах

## Проблема
Сейчас Hero-секция использует фиксированную высоту `h-[75vh]` для всех устройств. Изображения баннеров отображаются с `bg-cover bg-center`, что приводит к:
- На десктопе (широкие экраны): изображение хорошо заполняет контейнер
- На мобильных/планшетах (узкие экраны): изображение сильно обрезается, видна только центральная часть

## Решение
Адаптировать высоту Hero-секции и способ отображения изображений для разных размеров экранов:

### 1. Адаптивная высота контейнера
Изменить высоту Hero с фиксированной на адаптивную:
- Мобильные устройства: `h-[50vh]` или `h-[60vh]` — меньшая высота, чтобы изображение не так сильно обрезалось
- Планшеты: `h-[65vh]`
- Десктоп: `h-[75vh]` (как сейчас)

### 2. Адаптивное позиционирование фона
Для лучшего отображения на мобильных:
- Использовать `object-fit: contain` вместо `cover` ИЛИ
- Изменить `bg-position` в зависимости от устройства

### 3. Рекомендуемый подход — адаптивная высота
Наиболее простое и эффективное решение — сделать высоту контейнера адаптивной:

```text
Было:    h-[75vh]
Станет:  h-[50vh] sm:h-[60vh] md:h-[65vh] lg:h-[75vh]
```

## Технические детали

### Файл: `src/components/Hero.tsx`

**Изменение 1** — секция fallback (строка ~103):
```tsx
// Было:
<section className="h-[75vh] flex items-center justify-center bg-background">

// Станет:
<section className="h-[50vh] sm:h-[60vh] md:h-[65vh] lg:h-[75vh] flex items-center justify-center bg-background">
```

**Изменение 2** — секция loading (строка ~147):
```tsx
// Было:
<section className="h-[75vh] flex items-center justify-center bg-background">

// Станет:
<section className="h-[50vh] sm:h-[60vh] md:h-[65vh] lg:h-[75vh] flex items-center justify-center bg-background">
```

**Изменение 3** — основная секция карусели (строка ~154):
```tsx
// Было:
<section className="relative h-[75vh] w-full overflow-hidden">

// Станет:
<section className="relative h-[50vh] sm:h-[60vh] md:h-[65vh] lg:h-[75vh] w-full overflow-hidden">
```

**Изменение 4** — контейнер слайда (строка ~182):
```tsx
// Было:
<div className="relative w-full h-[75vh]">

// Станет:
<div className="relative w-full h-full">
```
(Использовать `h-full` вместо повторения высоты)

---

## Результат
- На мобильных (< 640px): высота 50vh — изображение менее обрезано
- На планшетах (640-768px): высота 60vh
- На средних планшетах (768-1024px): высота 65vh
- На десктопе (> 1024px): высота 75vh — как сейчас

Это обеспечит лучшую видимость изображений баннеров на всех устройствах без необходимости загружать отдельные версии изображений для мобильных.
