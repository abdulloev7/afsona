
# План реализации блока «Лучшие предложения»

## Обзор

Создание секции "Лучшие предложения" на главной странице сразу под баннером с карточками избранных товаров. Блок будет показывать товары с флагом `is_featured = true`, отсортированные по тегам и дате добавления.

---

## Визуальный результат

Блок будет содержать:
- Заголовок "Лучшие предложения" с подзаголовком
- Фильтр по тегам (Хит, Советуем, Новинка, Акция)
- Сетку карточек 4 в ряд (адаптивно: 1-2 на мобильных)
- Карточки с цветными бейджами, фото, названием, описанием, ценой, рейтингом и кнопкой "В корзину"

---

## Этап 1: Изменение структуры базы данных

Добавление новых полей в таблицу `products`:

| Поле | Тип | Описание |
|------|-----|----------|
| `is_featured` | boolean | Показывать в "Лучших предложениях" |
| `tags` | text[] | Массив тегов: "Хит", "Новинка", "Советуем", "Акция", "Эко" |
| `old_price` | numeric | Старая цена для акций (зачеркнутая) |
| `rating` | numeric | Рейтинг товара (1-5) |
| `reviews_count` | integer | Количество отзывов |

Миграция:
```text
ALTER TABLE products ADD COLUMN is_featured boolean DEFAULT false;
ALTER TABLE products ADD COLUMN tags text[] DEFAULT '{}';
ALTER TABLE products ADD COLUMN old_price numeric;
ALTER TABLE products ADD COLUMN rating numeric;
ALTER TABLE products ADD COLUMN reviews_count integer DEFAULT 0;
```

## Технические детали

### Логика сортировки
```typescript
const sortedProducts = products.sort((a, b) => {
  const getPriority = (tags: string[]) => {
    if (tags.includes('Хит')) return 1;
    if (tags.includes('Акция')) return 2;
    return 3;
  };
  const priorityDiff = getPriority(a.tags || []) - getPriority(b.tags || []);
  if (priorityDiff !== 0) return priorityDiff;
  return new Date(b.created_at).getTime() - new Date(a.created_at).getTime();
});
```

### Кэширование
- Используется React Query (`@tanstack/react-query`) для автоматического кэширования
- При обновлении товара в админке данные обновятся автоматически

### Адаптивность
- Мобильные: 1 карточка в ряд
- Планшеты: 2 карточки в ряд  
- Десктоп: 4 карточки в ряд

## Преимущества реализации

- **Расширяемость**: теги хранятся как массив строк - можно добавлять новые без изменения структуры БД
- **Гибкость**: товар может иметь несколько тегов одновременно
- **Производительность**: запросы с фильтрацией на уровне БД
- **UX**: плавные анимации, hover-эффекты, интуитивный интерфейс админки
